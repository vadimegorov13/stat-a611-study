# Your study data

Everything here belongs to you and is created by the app.

- `notes/` — personal notes, one Markdown file per note (`<note-id>.md`). Safe to read, back up, or edit (see ../AGENTS.md for the format).
- `note-revisions/` — automatic history of every note version (used by History / restore).
- `trash/` — notes deleted in the app.
- `progress.json` — attempts, flags, studied marks, exam checklist.
- `scratch.json` — scratch work typed under exercises.
- `backups/` — backups made from the Progress page or before a reset.
